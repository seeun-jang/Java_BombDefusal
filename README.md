# 💣 시한폭탄 해체 시뮬레이터  

Java의 조건문(`switch`, `if-else`)과 논리 연산자(`&&`, `||`) 학습을 위해 구현한 텍스트 기반 조건 판별 시뮬레이터

## Tech Stack
- **Language:** Java

## 게임 규칙 (해체 매뉴얼)
입력받은 단서(시리얼 번호, 배터리 개수)를 바탕으로 조건에 맞는 선을 잘라야 생존하는 게임.  

- 🔴 **빨간 선:** 시리얼 번호 짝수 `AND` 배터리 2개 이상
- 🔵 **파란 선:** 시리얼 번호 홀수 `OR` 배터리 2개 미만
- 🟡 **노란 선:** 절단 시 즉시 폭발

## 실행 방법
`Main.java` 실행 후 콘솔창의 안내에 따라 순서대로 값(시리얼, 배터리, 타이머 난이도, 자를 선)을 입력하면,  
조건 충족 여부에 따라 해체 성공 또는 폭발 결과가 출력됩니다.
